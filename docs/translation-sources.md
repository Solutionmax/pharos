# Translation sources

Application UI and default mail translations are maintained in `lang/*.json`.
Native Laravel validation, authentication, password-reset and pagination lines in
`lang/nl`, `lang/de` and `lang/es` are based on Laravel-Lang/lang, commit
`a3504212776c77984273beb9b7ef9ecbacc2e4e4` (2026-10-07), with local field names.

Upstream: https://github.com/Laravel-Lang/lang
